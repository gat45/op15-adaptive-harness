# Lacunes d'implémentation

P0 : `Verifier` est un stub sans oracle externe ; aucune permission/exécuteur ; état durable sans états `STARTED/EFFECT_APPLIED/CONFIRMED` ni réconciliation ; la sortie llama.cpp n'alimente aucune preuve.

P1 : pas de fonction d'utilité, objectifs, RAG/mémoire, trace active, métacognition intégrée, streaming/retry HTTP ni télémétrie matérielle.

P2 : pas de CI, jeux scellés, baselines, résultats, coût par réussite ou benchmark.
